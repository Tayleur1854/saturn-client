## About
Saturn Client is a personal fork of [Meteor Client](https://github.com/MeteorDevelopment/meteor-client) modified by Bills310. It features a custom green color scheme, a unique Saturn-themed title screen, custom Discord RPC, and more to come.

**Minecraft Version:** 1.21.11  
**Mod Loader:** Fabric  
**Based on:** [Meteor Client](https://github.com/MeteorDevelopment/meteor-client)

## Features
- Custom green (`#03ff10`) GUI color scheme
- Saturn-themed animated title screen
- Custom Discord Rich Presence
- All original Meteor Client features
- More custom features coming soon

## Usage
### Building
- Clone this repository
- Run `./gradlew build`
- The built jar will be in `build/libs/`

### Installation
1. Install [Fabric Loader](https://fabricmc.net/use/installer/) for Minecraft 1.21.11
2. Download [Fabric API](https://modrinth.com/mod/fabric-api) for 1.21.11
3. Drop `saturn-client-x.x.x.jar` and Fabric API into your `.minecraft/mods/` folder
4. Launch Minecraft with the Fabric profile
